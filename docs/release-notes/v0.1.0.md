首个公开版本。收艇后不用再手工记账：截一张游戏日志窗口，或者直接从聊天框读，程序把这一轮捞到的物名和数量读出来，按卖店价算成收益，归到角色和艇上。

## 新功能

- **收艇记账**：截游戏日志窗口、拖入、`Ctrl + V`、读剪贴板、选文件，五种取图方式。识别结果是逐行列出的，可以改数量、切 HQ、在歧义时选候选、给词表外的物名手填单价，合计实时刷新，确认后才入账。
- **直接读聊天框**：不截图，进程外只读拿聊天缓冲区，不会认错字也不会漏掉 HQ 标记；也可以开自动监听，收完艇自动出账。这条路不默认开启，由你主动触发。
- **按艇记账**：层级是 角色 → 艇 → 记录。靠「潜水艦「X」の探索完了」把这一轮的产出归到对应艇上，识别串了的时候每行的艇归属可以手改。
- **收益统计**：总收益 / 日均 / 月均 / 年均四张卡，日/月可切的走势图，按角色、按艇、按道具三种占比，已入账记录可逐条删除，也能导出 CSV。金额过亿自动换单位。
- **备份**：JSON 导出与整体替换导入，导入前自动留一份存档。
- **简体中文与日文界面**：界面文案与道具名一起切换，加一门语言只要放一个资源文件。
- **调试模式**：把从游戏聊天框读到的原文记成 txt。用的是别的语言客户端时，把这个文件发回来就能补上对应语言的识别规则。
- **更新检查**：只查最新版本号，不下载不安装；支持系统代理、直连与自定义代理。

用法与设计说明见 [README](https://github.com/huaxianyan/FFXIVSubmarineLedger/blob/v0.1.0/README.md)。
